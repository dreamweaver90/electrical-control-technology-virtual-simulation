# 电气控制虚拟仿真系统

**Electrical Control Technology Virtual Simulation System**

纯前端（无构建工具、无后端）的**电气 + 气动接线仿真与排故教学平台**。
在浏览器里拖放器件、接线、通电仿真、读仪表、设置故障供学生排查 —— 打开的即是一个可以"动手接线"的虚拟配电盘。

- **技术栈**：原生 HTML / CSS / ES Module JavaScript（零依赖、零构建）
- **仿真内核**：电气走 MNA 相量数值求解（50Hz 复数网络），气动走结构层等压传播
- **适用场景**：电气控制线路实训、PLC 前置基础教学、气动回路教学、排故（故障诊断）考核

---

## 功能一览

### 配电盘与接线
- **两种盘面布局**：有线槽（分行排布，贴近真实配电柜）与无线槽（自由摆放），滚轮缩放、空白拖动平移
- **两类介质**：导线（电气，黄/绿/红/蓝选色）与气管（气动，黑/蓝选色，圆柱渐变 + 悬链线路径），两者端子不可混接
- **接线规则**：端子有接线数上限；**带电端子禁止接线**（结构层实时判定），**带压气管默认禁止接线**（可配置放开）
- **导线交互**：右键设线标、颜色、线标显示位置；双击删除；悬停高亮；「显示连接线」开关可隐藏连线（仅影响显示，不影响仿真）
- **撤回 / 重做**：`Ctrl+Z` / `Ctrl+Shift+Z`，结构操作（接线、删线、放置、删除、拖动、清除、导入）快照式回退；参数与运行状态不回退

### 元件库
右上角悬浮面板，两个页签：
- **独立元件**：电源与配电（三相 AC / 直流电源 / 整流器 / 变压器 / 断路器 / 隔离开关 / 熔断器）、控制器件（接触器 / 继电器 / 时间继电器 / 热继电器 / 按钮与按钮盒 / 行程开关）、负载与仪表（三相异步电动机 / 指示灯模块 / 电压表 / 电流表 / 电能表 / 指针转速表 / 电阻）、接线与机械（接线排 / 十字滑台）、气动（气源 / 气路开关 / 调压阀 / 电磁阀模块 / 并联模块 / 双作用气缸 / 执行模块 / 磁性传感器）
- **场景组合**：一键铺好整套回路（基础控制回路、正反转、顺序启动、气动机械手等），拖到盘面即加载

### 仿真（每 50ms 一次扫描）
- **电气**：闭合触点按时序动作 → 线圈得电（滞回判定）→ 电机启停与正反转 → 仪表读数 → 短路判定与断路器跳闸 / 熔断器逐相熔断
- **电机**：三相绕组电压相量平衡判定（幅值 + 相位差 120°）决定"能否转"，相序决定正反转；匀加速起动 / 断电减速；堵转时阻抗切换为 6× 电流并触发热继电器链
- **气动**：压力源注入 → 等压传播（调压阀动态源级联收敛）→ 双线圈电磁阀位置状态机 → 气缸按行程时间积分伸缩；**串气**（同分量多压力）与**漏气**（有压未接开口）自动检测
- **告警栈**：短路跳闸 / 短路无保护 / 串气 / 漏气 / 双线圈同时得电 / 传感器接交流或超压，统一列表呈现，漏气端子带 💥 标记
- **万用表**：表笔可拖到任意端子测量交直流电压、通断电阻，**电阻 < 10Ω 蜂鸣**

### 排故教学
- 进入排故模式并选择难度（简单 / 中等 / 困难），系统在**已接线处随机注入故障**（断路 / 触点粘连）
- 学生用万用表测量排查，点击可疑点提交判定，对错都记入排故面板
- 故障范围完全配置驱动：每个端子对与端子都能声明可设故障的等级，**气路永不设故障**

### 工程与场景
- **导出 / 导入工程 JSON**：完整保存器件、参数、导线、线标；导入自动还原
- **场景文件**：`scenes/<id>.json`，在主配置登记后即可在元件库中一键加载

## 快速开始

ES Module 在 `file://` 协议下无法加载，**必须用 HTTP 服务器打开**（双击 HTML 会白屏）：

```bash
cd 仿真系统
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

启动后从左下角/右上角打开**元件库**，拖一个"场景组合"到盘面即可看到整套回路；也可以从零开始拖器件接线。

> 浏览器要求：支持 ES Module 的现代浏览器（Chrome / Edge / Firefox / Safari 新版本）。3D 工作台视窗需要 WebGL。

## 典型使用流程

1. 从元件库拖放器件（或拖"场景组合"一键铺好整套回路）；
2. 点端子 → 点端子接线（带电/带压端子默认禁止接线），右键导线设线标与颜色；
3. 点击开关 / 按钮 / 热区，或右键器件改参数 → 仿真每 50ms 运行一次；
4. 观察器件动画与文字显示，读电压表 / 电流表 / 电能表 / 万用表，看告警栈提示；
5. 结构操作可撤回 / 重做（`Ctrl+Z` / `Ctrl+Shift+Z`）；
6. 导出工程 JSON 存档或分享，导入即可复原；
7. **排故练习**：进入排故模式（选难度）→ 系统注入故障 → 万用表排查 → 点击故障点提交判定。

## 架构要点

### 双层网络模型（结构层 / 数值层分离）

| 层 | 实现 | 用途 |
|---|---|---|
| 结构层 | `buildGraph()`：导线 + 闭合触点 + 恒连 = 0Ω 边（并查集） | 短路布尔判定、岛划分、带电/带压检测 |
| 数值层 | `solveNetwork()`：真实阻抗支路（MNA 矩阵，50Hz 相量） | 节点电位、支路电流，一次求解全部支路 |

电气与气动彻底隔离：`buildGraph({media})` 按介质过滤导线与端子对，电路图与气路图互不干扰。

**每 tick 流程**：`buildGraph()` → 短路检测与断路器跳闸 → `solveNetwork()` → 逐器件 `scan()`（触点动作、线圈判定）→ `computePneumatics()` → 逐器件 `scanPneumatic()`（气缸积分、阀位置机）→ 告警栈刷新 + 漏气端子标记 → 万用表刷新。

### 配置驱动优先

器件行为差异尽量用 JSON 表达，代码只保留通用引擎：

- **四类端子对**：`contacts`（触点，`when` 表达式 + 时序）、`loads`（负载/线圈，可调阻抗或计算钩子）、`permanent`（恒连）、`sensors`（串联测流支路）
- **外观绑定**：图层显隐（`bind` 表达式）、元素 class（`classBind`）、元素动画（`anims`：直线移动 / 绕点旋转 / 属性插值，可同步端子坐标）
- **参数容器统一**：铭牌定值、面板可调项、逻辑状态键、运行时值全部存 `params`
- **能力协议**：`power` / `speed` / `trip` / `relative-position` 等能力在注册表声明，工厂创建时校验契约

新增器件通常 = 写一个 `components/<id>.json` + 在 `system_config_v3.json` 登记；只有需要新数值模型时才写代码。完整字段清单与二次开发案例见 **`配置说明.md`**。

## 开发说明

- **无构建步骤**：改完源码刷新浏览器即可（改配置 JSON 同理）
- **调试**：浏览器控制台可用 `G` 单例访问运行时对象（`G.app` / `G.panel` / `G.solveResult` / `G.pneumatics`）
- **扩展流程**：`components/<id>.json` 定义器件 → `system_config_v3.json` 的 `components` 列表登记 → 刷新即出现在元件库
- **注意**：临时验证脚本若使用 ES Module，需要临时 `package.json {"type":"module"}`（用完删除）
